GUERRERO VS NAVES - JUEGO WEB

1. Coloca las imágenes originales del juego dentro de:
   assets/

2. Deben llamarse exactamente:
   fondo.png
   walk.png
   atak.png
   down.png
   up.png
   nave.png
   misil.png

3. Para probarlo:
   abre index.html en Google Chrome.

4. Para publicarlo:
   sube TODOS los archivos a un repositorio público de GitHub
   y activa GitHub Pages.

CONTROLES:
1 = Nivel fácil
2 = Nivel medio
3 = Nivel experto
Flecha izquierda/derecha = mover
Flecha arriba = saltar
Flecha abajo = agacharse
Espacio = atacar
Enter = reiniciar

NOTA:
Las imágenes no están incluidas porque son los archivos gráficos
del juego original. Debes copiarlas a la carpeta assets.
